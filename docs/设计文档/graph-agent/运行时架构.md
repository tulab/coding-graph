# 设计文档 · agent runtime 架构

## 1. 层次结构

graph-agent 运行时五层，顶层 Agent Runtime 持有下方四层：

```
┌──────────────────────────────────────────────┐
│              Agent Runtime                  │  运行时门面：装配、生命周期、持有会话
├──────────────────────────────────────────────┤
│              Workspace Layer                │  Task / Plan / Files / State / Scope（本次仅 State 占位）
├──────────────────────────────────────────────┤
│             Capability Layer                │  SkillLoader + ToolRegistrar
├──────────────────────────────────────────────┤
│              Context Layer                  │  System / Skill / Workspace / History（PromptComposer）
├──────────────────────────────────────────────┤
│              Pi Agent Core                  │  模型 / loop / 工具执行（pi-coding-agent SDK）
└──────────────────────────────────────────────┘
```

## 2. 分层职责

| 层 | 职责 | 位置 |
|---|---|---|
| Agent Runtime | 顶层门面：创建会话、持有各层实例、编排 skill 加载与工具注册 | `graph-agent/lib/runtime.js` |
| Workspace | 任务 / 计划 / 文件 / 状态 / 范围；本次仅 State 最小占位 | `graph-agent/lib/workspace.js` |
| Capability | SkillLoader：skills 状态（loadedSkills、SKILL.md 缓存），函数 `loadSkill` / `unloadSkill`；ToolRegistrar：tools 状态（MCP JSON → AgentTool → `state.tools`），函数 `registerTool` / `unregisterTool` | `graph-agent/lib/skill-loader.js` `graph-agent/lib/tool-registrar.js` |
| Context | PromptComposer：每轮组合 System / Skill / Workspace / History 进 systemPrompt | `graph-agent/lib/prompt.js` |
| Pi Agent Core | 模型、agent loop、工具执行、SSE 事件 | pi-coding-agent SDK |

## 3. 关键机制

- **skill 全文注入**：`SkillLoader.loadSkill` 改 loadedSkills；`PromptComposer` 在 `before_agent_start` 每轮把 loadedSkills 全文拼进 systemPrompt。内容进提示词不进对话流；必须总返回完整提示词，维持无 cwd、无默认骨架。
- **工具动态更新**：`ToolRegistrar.registerTool` 逐个注册 `scripts/tools.json`（MCP 格式）声明的工具 → 构建 AgentTool → `session.agent.state.tools = 新数组`（pi-core 文档规定的替换机制，下一轮生效）。
- **LLM 面**：只暴露 `loadSkill` / `unloadSkill` 两个薄壳工具（薄壳调用 `SkillLoader.loadSkill` / `unloadSkill`）+ 已注册 skill 工具；不开 read，维持禁基础四工具定位。
- **MCP tools.json 约定**：每个 skill 的 `scripts/tools.json`，MCP 格式声明工具（name / description / inputSchema），从 JSON 加载，不从实际脚本直接加载。execute 由运行时按 skill 挂 handler。

## 4. loadSkill 调用链

```
模型 → loadSkill("growing-graph")
  → SkillLoader.loadSkill → loadedSkills += SKILL.md 全文
  → ToolRegistrar 扫描 .agents/skills/growing-graph/scripts/tools.json → registerTool 逐个注册 → state.tools 并入
下一轮 before_agent_start → PromptComposer 拼 loadedSkills 全文 → 模型可见 skill 规则 + 新工具
```
