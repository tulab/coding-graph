# 设计文档 · graph-viz 交互

| 交互 | 行为 |
|---|---|
| 图谱选择 | 本人图谱下拉（最近更新优先），切换即重建视图 |
| 滚轮 / 双击 / 缩放按钮 | 相机缩放（并置 userZoomed 冻结阈值） |
| 空白处拖拽 | 平移画布 |
| 节点拖拽 | 左键按住节点 → 移动该节点（画布不平移） |
| 悬停节点 | 属性浮层 + 节点色高亮环 |

## 节点拖拽时序

```mermaid
sequenceDiagram
    participant U as 👤 用户
    participant S as 👁️ sigmaEngine
    participant F as 🌀 d3-force
    participant C as 🖥️ 画布

    U->>S: 左键按下节点（downNode）
    S->>S: 禁用画布平移
    U->>S: 拖动超过 4px
    S->>F: pause() 暂停仿真
    S->>S: viewportToGraph 写节点坐标
    S->>C: 重绘 · 虚竖线重算
    U->>S: 松开（mouseup）
    S->>S: 恢复平移 · 记录拖放位置
    S->>F: resume() 温和续跑
    S->>S: 重算卡片临界
```
