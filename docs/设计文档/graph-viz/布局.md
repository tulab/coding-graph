# 设计文档 · graph-viz 布局

| 布局 | 特性 | 默认 |
|---|---|---|
| 确定性网格 | 按 stage 分列、组内按 level 排块；间距保证浅缩放即可看卡 | 关闭 |
| d3-force 力导向 | 关系驱动、forceX 拉到 stage 列中心保持分列、收敛后自适应 | **开启** |

## 1. 确定性网格

按 stage 切分节点，组内按 level 顺序自左向右排块（level 顺序经接口下发的维度字典获得）；单元 `340×190`、同 stage 内相邻 level 块间距 260、相邻 stage 间距 360（≥ 卡宽，浅缩放即可看卡且不重叠）。返回节点坐标、stage 分界虚竖线 x、整体 y 范围；隐藏节点剔除时不参与排布。

## 2. d3-force 力导向

force simulation 实时把坐标写回图并驱动重绘；`forceX` 拉向各 stage 列中心，保持"需求 / 设计"分列语义，虚竖线与适配视图按当前节点坐标动态重算。

- 关系期望长 240、斥力 -500、碰撞半径 110、起始 alpha 0.55（首帧不猛弹）；
- 收敛后按最终坐标重算卡片临界并适配；关闭恢复确定性网格坐标；
- 维度剔除时隐藏节点退出仿真（见《维度筛选》）。
