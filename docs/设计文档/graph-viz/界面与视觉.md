# 设计文档 · graph-viz 界面与视觉

## 1. 配色

12 色低饱和调色板，节点类型码经确定性哈希映射取色；不绑定业务枚举（枚举经接口下发）。半透明态用预乘 rgba（配合 sigma 的预乘混合），避免非预乘导致的"发光"假象。

## 2. 工具栏

浅米黄底、墨色正文、1px 圆角细边框、fixed 悬浮；品牌 / 图谱选择 / 缩放 ± / 适配视图 / 力导向开关 / 维度筛选入口。维度筛选面板为 antd Segmented 三段按钮（仅此面板用 React）。

## 3. 图例

右下角悬浮卡片，按层级（文本层 / 实体层）分组，类型 → 色点 + 名称；随图谱重建。
