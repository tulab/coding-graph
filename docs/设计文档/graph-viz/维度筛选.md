# 设计文档 · graph-viz 维度筛选

维度集合由接口下发的维度字典 `graph.dims` 驱动，每个取值三态循环：

```mermaid
flowchart TD
    A["🧩 点选维度取值三态<br/>显示 / 半透明 / 隐藏"] --> B{命中取值状态}
    B -->|hidden| C["reducer: hidden=true<br/>节点与标签不绘制"]
    B -->|semi| D["reducer: alpha 淡化<br/>WebGL 预乘色 + 标签层 globalAlpha"]
    B -->|visible| E["原样显示"]
    C --> F{力导向状态}
    F -->|开| G["force.setVisible 剔除<br/>仅隐藏节点退出仿真<br/>开关与运行不受影响"]
    F -->|关| H["仅可见节点重排<br/>不留空位 · 重适配"]
    C --> I["关联边隐藏"]
    D --> J["关联边淡出"]

    classDef act fill:#87CEEB,stroke:#333,stroke-width:2px,color:darkblue
    classDef dec fill:#FFD700,stroke:#333,stroke-width:2px,color:black
    classDef out fill:#FFB6C1,stroke:#DC143C,stroke-width:2px,color:black
    class A,C,D,E,G,H,I,J act
    class B,F dec
```

**与力导向的协作**：切换维度**不影响力导向的开关与运行**——隐藏节点仅退出仿真（`setVisible` 只让可见节点继续受力），不重排坐标、不拉相机；仅当力导向关闭时才整图重排。半透明态不改变拓扑，只做自身 alpha 淡化（WebGL 圆点用预乘色、标签层用 `globalAlpha`），关联边随之淡出 / 隐藏。
