# 设计文档 · 架构概览

## 1. 总体架构

```
┌────────────────────────── coding-graph 智能体 ──────────────────────────┐
│  graph-agent（node 后端，待建）                                          │
│  · pi agent SDK（@mariozechner/pi-coding-agent）                         │
│  · createAgentSession 装配会话，禁用基础四工具（read/bash/edit/write）     │
│  · 注入自定义工具：dynamic-graph 写接口 + 探查读接口                       │
│  · 按 skills/coding-graph/SKILL.md 规则构建需求图谱                        │
└──────────────────────────────┬───────────────────────────────────────────┘
                               │ REST / JSON（X-Identity，写 / 读）
┌──────────────────────────────┴───────────────────────────────────────────┐
│                    dynamic-graph（基础设施，独立项目）                      │
│  FastAPI · 四层 RPC：graph / schema / instance / transaction               │
│  SQLite 单库：图谱 / 类型字典 / 操作记录 / 实例（按 graph_id 分区）          │
└──────────────────────────────┬───────────────────────────────────────────┘
                               │ REST / JSON（X-Identity，只读）
┌──────────────────────────────┴───────────────────────────────────────────┐
│  graph-viz（node 前端，沿用 web-frontend 半成品，仅可视化）                 │
│  Vite + sigma.js + graphology · 多尺度渲染 / stage 分组 / dims 维度筛选    │
└───────────────────────────────────────────────────────────────────────────┘
```

## 2. 分层职责

| 层 | 职责 | 位置 |
|---|---|---|
| graph-agent | 智能体运行时：pi agent SDK 会话、图谱构建自定义工具、按 SKILL 规则写图 | `graph-agent/`（node，待建） |
| graph-viz | 只读可视化：读 dynamic-graph 读端点并渲染 | `graph-viz/`（原 web-frontend） |
| 基础设施 | 图存储 + 四层 RPC + X-Identity 身份校验 | dynamic-graph（独立项目） |

## 3. 模块划分

```
coding-graph/
├─ graph-agent/       node 后端（待建）：pi agent SDK 装配 + 图谱构建工具
├─ graph-viz/         可视化前端（沿用 web-frontend 半成品）
│   ├─ src/core/api.js     通用客户端（注入 X-Identity）

├─ skills/coding-graph/   agent 构建规则（SKILL.md）
├─ extract/              领域语料（agent 输入素材）
└─ docs/                 需求 / 设计文档
```

## 4. 协作约定

- **身份**：dynamic-graph 为微服务、不内置鉴权；调用方（graph-agent / graph-viz）注入 `X-Identity` 头（base64(JSON)，含 user_id）；缺失 / 非法即 401。
- **graph-agent 只写 + 探查**：经写接口装配图谱与实例，经 `graph/overview`·`neighbours` 探查现状、防重复；不暴露 schema 增删改、整图删除等建模级操作给 agent。
- **graph-viz 只读**：走读端点——`GET /api/graph`（列表）、`GET /api/graph/{graph_id}`（元数据 + 维度字典）、`POST /api/schema/types`、`POST /api/instance/object|link`。
- **schema 单一事实源**：《设计哲学/需求图谱Schema设计.md》定义节点 / 关系 / 维度字典，agent 按此构建，不发明新类型。
- **构建规则**：节点原子性、关系分层（文本层内 / 实体层内 / 跨层）、删除高危先探查，见 `skills/coding-graph/SKILL.md`。
