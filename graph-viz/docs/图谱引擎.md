# 实现 · 前端图谱引擎

> sigma 3.0.3 为纯 WebGL 节点渲染；多尺度卡片/文字在 Canvas 标签层绘制。
> 相机事件用 `camera.on("updated")`（sigma 3 没有 `cameraUpdated` 事件）。
> 交互事件：`downNode / clickNode` 等由 `createInteractionListener("down")` 动态拼接触发（非字面量）；sigma 3 不发射 `moveNode / clickStage`。

## 1. 建图（`sigmaEngine.js`）

```js
graph.addNode(id, { x, y, size, label, color, baseColor, forceLabel: true,
                    ntype, tname, level, stage, dims, title, content, props });
// color/baseColor：baseColor 是原色快照。卡片态 reducer 把 color 置全透明隐藏本体，
// 标签层卡片/高亮描边读 baseColor，不被连带变透明。
graph.addEdgeWithKey(id, source, target, { type: "arrow", color: "#b7ab99", size: 2,
                    label: typeName, tname: typeName, forceLabel: true });
```

## 2. 多尺度渲染（`nodeProgram.js`）

`drawLevelNode(ctx, data)`：`data.x/y` 为屏幕坐标，`data.size` 为屏幕尺寸。尺度由 `scaleFromRatio(ratio)` 决定，卡片临界**动态**：

- scale-1：矩形卡片（type 徽标 + title + content），**不透明**填充；
- scale-2：圆 + title；
- scale-3：退化为圆点。

**卡片态本体圆点直接隐藏**：reducer 把 `color` 置为全透明（`#00000000`）。sigma 的可见色与拾取 id 是同顶点缓冲里的独立字段（fragment 按 `PICKING_MODE` 取 `a_id`）——圆点不绘制但悬停/点击仍命中，且任意缩放深度都不会有圆点从卡边冒出。`BODY_SIZE {1:13, 2:13, 3:5}`（卡片边界不换尺寸，无退出闪动）；卡片态 reducer 单独置 `size=CARD_PICK_SIZE(40)` 只作拾取半径（屏上≈`size/√ratio`，典型浏览缩放约 70~90px，整卡可点拖）。

## 3. 布局（可切换）

### 3.1 确定性布局（`layout.js`）

网格 `CELL 340×190`、块间距 `BLOCK_GAP 260`、stage 间距 `STAGE_GAP 360`（间距 ≥ 卡宽，保证浅缩放即可看卡且不重叠）。按 stage 分组，组内按 level 排块；隐藏节点不参与（筛选时剔除）。

### 3.2 d3-force 力导向（`forceLayout.js`）

`link` 期望长 240、`charge` 斥力 -500、`collide` 半径 110、`x`/`y` 列牵引 0.08/0.04、`velocityDecay 0.55`、起始 `alpha 0.55`（首帧不猛弹，初始化温和）。**默认开启**，收敛 `end` 后重算卡片临界并适配。

- `setVisible(ids)`：维度剔除/恢复时重建仿真节点与关系集，隐藏节点退出受力，可见节点继续跑。
- `pause()/resume()`：节点拖拽期间暂停仿真（防拉扯），结束后温和续跑（`alpha 0.2`）。

## 4. stage 虚竖线

`createStageDividers`：按当前节点坐标统计各 stage 列边界（隐藏节点不计入），相邻 stage 边界中点作分界线；容器内建 SVG，随相机 `updated` 与布局 tick 重算。

## 5. 维度筛选（antd Segmented + reducer）

面板用 antd `Segmented` 三段按钮（显示/半透明/隐藏），维度集合来自 `graph.dims` 字典。状态变更经 `setDimState` 落库：

- **hidden → 剔除**：
  - 力导向**开着**：不影响力导向开关与运行——只 `force.setVisible` 让隐藏节点退出仿真，可见节点继续受力；不重排坐标、不拉相机；
  - 力导向**关**：仅可见节点重排确定性布局（隐藏节点不留空位），整图重适配。
  - 关联边一并隐藏。
- **semi → 节点自身 alpha 淡化**：reducer 把颜色改为预乘 rgba（sigma WebGL 用 `blendFunc(ONE, ONE_MINUS_SRC_ALPHA)`，非预乘会"发光"），并置 `alpha` 让标签层 `globalAlpha` 同步淡化；关联边淡出。
- **visible → 完整显示**，恢复剔除的节点。

## 6. 边标签（`drawEdgeLabel`）

`renderEdgeLabels` 开启，所有边 `forceLabel` 常绘制，10px 类型名小字沿边旋转、端点缩进、边太短省略。**卡片态也画**：线段两端截断到卡片边缘（矩形交点），标签与箭头只出现在两卡之间；WebGL 边本体的方向箭头被不透明卡片盖住，目标端补画小箭头。

## 7. 悬停高亮与节点拖拽

- `drawNodeHover` 画节点色描边环（scale-1 沿卡片，否则沿圆点），用 `baseColor`；并隐藏 `.sigma-hoverNodes` 层。
- **节点拖拽**：`downNode`（仅左键）置 `camera.enabledPanning=false`（`Camera.setState` 对 panning 禁用时忽略 x/y → 画布不平移）；拖动用 `viewportToGraph` 写节点坐标；mouseup 恢复平移、记录拖放位置、重算卡片临界。空白处拖动仍平移画布。拾取走 WebGL picking 缓冲，卡片态圆点透明仍可点。

## 8. 视图适配与卡片临界（`sigmaEngine.js` / `scale.js`）

sigma 3 相机工作在归一化空间。`fitMetrics` 用 `normalizationFunction` 求可见节点 bounds 的归一化中心，设 ratio=1 用 `graphToViewport` 实测跨度，反推 ratio 使图完整落入视口（留 6% 边距）。

卡片临界动态计算：在 ratio=1 参考系投影全部可见节点。屏幕距 = 参考距/ratio（ratio 越小越放大），卡片不重叠 ⟺ `dx/ratio>=GW 或 dy/ratio>=GH`，逐对允许的最大 ratio 为 `max(dx/GW, dy/GH)`，**全局取最小值**（GW/GH 含 `+24px` 间隙）；再夹在适配 ratio×0.9 之下（初始概览落圆点态，≥0.25）。布局变化（建图/力导向收敛/维度剔除/节点拖拽）后重算。

**进出对称**：判定是**单一阈值** `cardMaxRatio`（进/出都用它比较，方向无关），但它在布局变化时会重算——力导向收敛会把图压密，导致阈值变化（实测 0.367→0.271），若用户在收敛前放大、收敛后缩小就会穿越两个不同值。修复：用户**已手动缩放**（滚轮/缩放按钮/双击）后，收敛**不再重算临界、也不 `fit` 拉回相机**，阈值冻结 → 一次"放大→缩小"循环穿越同一值；仅用户**未干预**时，收敛做一次干净的重算+适配。后续收敛（拖拽/维度后）只重算临界、不拉相机。

## 9. 悬停浮层（`tooltip.js`）

`enterNode/leaveNode` → `graphToViewport` 定位 DOM 浮层；相机移动时隐藏，拖拽开始时也隐藏。
