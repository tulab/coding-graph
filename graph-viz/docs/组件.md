# 实现 · 前端组件

> 组件为轻量函数模块（返回 DOM 元素 + 回调）；仅维度筛选面板用 React 挂载 antd `Segmented`。

## 1. Toolbar（`components/Toolbar.js`）

`createToolbar({ graphs, onGraphChange })` → `{ el, swap }`

工具栏常驻，跨图谱切换不重建；`view` 经 `viewRef` 间接持有，`swap({ view, meta, currentGraphId })` 换绑。

| 区块 | 内容 | 回调 |
|---|---|---|
| 品牌 | 「知识图谱」标题 | — |
| 图谱选择 | 内嵌 `GraphSelect`（本人图谱下拉） | `onGraphChange(gid)` 触发重载 |
| 缩放 | ＋ / － / ⤢ 三按钮 | `view.zoomBy(1.5)` / `zoomBy(1/1.5)` / `view.fit()` |
| 力导向 | 开关按钮（`kg-btn.on` 激活态） | `view.setForceLayout(on)` / `view.isForceOn()` |
| 维度筛选 | 内嵌 `DimFilter` | `view.setDimState(dimKey, valueCode, next)` |
| 图例（右下角悬浮卡片） | 按层级分组，类型 → 色点 + 名称 | 只读（`nodeColor`） |

样式：`position: fixed` 左上、浅米黄 `rgba(247,241,227,.94)`、圆角 + 细边框 + 阴影。

## 2. GraphSelect（`components/GraphSelect.js`）

`createGraphSelect({ graphs, current, onChange })` → `{ el, getValue, setValue }`

- 原生 `<select>` + 标签「我的图谱」；选项为当前用户（本人）的图谱（`POST /graph/list`，ids 空=全部，已按身份过滤）。
- `setValue(id)` 用于图谱切换后同步选中态。

## 3. DimFilter（`components/DimFilter.jsx`）

`createDimFilter({ dims, onChange })` → `{ el, getState, setDims }`

- 触发按钮 + 下拉面板（`kg-popover`）；点击外部关闭。面板为 React 根（antd `ConfigProvider` + `Segmented`）。
- 由图谱声明的维度字典 `graph.dims` 驱动：每个维度一组，组内每个取值一行，antd `Segmented` 三段按钮
  `显示 / 半透明 / 隐藏`（左中右）。
- 状态内部维护 `{ [dimKey]: { [code]: 'visible'|'semi'|'hidden' } }`，切换后 `render()` 并回调 `onChange(dimKey, code, next)`。
- `setDims(dims)` 用于图谱切换后重建面板（各值重置为「显示」）。

## 4. 状态流向

```
DimFilter.onChange ──▶ view.setDimState ──▶ 剔除/退出仿真(hidden) 或 边淡化(semi) ──▶ reducer ──▶ sigma.refresh
```

视图（view）与筛选器各自持有状态副本，切换时同步。`hidden`：力导向开着 → 仅退出仿真（开关与运行不受影响，不拉相机）；
力导向关 → 可见节点重排（剔除不留空位）并重适配。`semi` 只改节点自身 alpha（WebGL 预乘色 + 标签层 globalAlpha），不重排。
